# F. マルコフ連鎖 / 拡散方程式の陰解法

## 題材

- Pは16 × 16の確率行列。正の乱数 + 0.05を行ごとに正規化したもので、全要素が正なので既約かつ非周期になる。
- 生成行列はQ = P − Iとした。プランでは独立に作る想定だったが、こうするとexpm(Qt)の定常分布がPのπと一致し、関門（4）「expm(Qt)の定常分布が(1)と一致」をそのまま確かめられる。
- 拡散は1次元、16点、Neumann境界の離散ラプラシアンLで、M = I − r L（r = 0.5）。Lの行和と列和が0なので、陰解法M u′ = uは総量Σuを保存する。`lu_fact(M)`を1回取り、`lu_solve`で100ステップ進める。

## 計測

計測用のfixtureはn = 256 / 1024 / 4096のP、Q = P − I、M、u0。4つの経路を別々に測った。

- `lu_solve`: `lu_fact(M)`は計測区間の外で1回だけ取り、1ステップは`lu_solve` 1回（右辺1本）。陰解法の時間発展の1ステップにあたる。
- `expm`: `expm(Q)`。numo-linalg-altとcumoはPadé(8) + scaling and squaring。CuPyとscipyの実装の次数は確かめていない。
- `matrix_power`: `matrix_power(P, 64)`。CumoとCuPyは二乗法。numo-linalg-altは63回の積を順に取るので、CPUの表には載せない（[numo-linalg-alt-notes.md](../numo-linalg-alt-notes.md)の3）。
- `eig`: `eig(Pᵀ)`。どの実装も`geev`（GPUでは`cusolverDnXgeev`）。

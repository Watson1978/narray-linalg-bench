# B. ガウス過程回帰

## 題材

- fixtureは、既知の(ℓ, σ_f, σ_n) = (0.3, 1.0, 0.1)のRBFカーネルを持つGPから引いた1本の関数に、ノイズを加えたもの。入力は2次元の一様乱数。
- smallはn = 64、テスト点は6 × 6の格子（36点）。
- 対数周辺尤度は`−½ yᵀα − Σ log L_ii − (n/2) log 2π`で、`L = cholesky(K)`、`α = cho_solve(L, y)`。
- 格子は(ℓ, σ_f, σ_n)のそれぞれについて、生成値の1.5^k倍（k = −3..3）。合わせて7³ = 343点。

## 計測

1ステップは、対数周辺尤度の1回の評価（カーネル行列を作る、`cholesky`、`cho_solve`、`log diag`の和）とした。プラン §7の表題には`slogdet`も入っているが、実際のGPの超パラメータ探索では`cholesky`の対角からlog detを取るので、`slogdet`で2度目の分解はしない。そのため1ステップには入れていない。

別のバッチの中央値どうしの比なので、ラウンド内の対にはなっていない。GFLOP/sは、`cholesky`のn³/3だけを数えた値（1ステップのほかの処理はO(n²)で、n ≥ 2048では無視できる）。

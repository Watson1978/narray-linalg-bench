# E. Vandermonde最小二乗

## 題材

- smallはm = 256点（[−1, 1]に等間隔）、次数7（n = 8列）のVandermonde行列V。真の係数に、標準偏差1e-3のノイズを加えてyを作った。
- ランク落ち版のV′ は、Vの8列目を3列目で、7列目を2列目で置き換えたもの（ランク6）。
- 特異値の切り捨ての閾値は、numo-linalg-alt、numpy、CuPyで既定値が違う（altの`lstsq`はeps、numpyはmax(m,n)·eps、CuPyの`pinv`は1e-15）。同じアルゴリズムで比べるため、`lstsq` / `pinv` / `null_space`には、どの実装にもmax(m,n)·epsを明示的に渡している。

## 関門（small、fp64、2026-10-01）

最小二乗解どうしの差はcond(V)倍まで許されるので、condで割ってから比べる。正規方程式はcond² で割る。

- tolは、Numoの最大値（1.1e-15）の10倍を切り上げて、2e-14にした。
- 物理量（残差ノルム0.01577、cond 231.0、係数誤差、最小ノルム3.633）は、4実装で一致した。
- CuPyの値は、多くの関門でCumoと同じ桁まで一致する。どちらもcuSOLVERを呼んでいるため。
- numo-linalg-altの`lstsq`は`driver:`を受け取るが使わない（常に`gelsd`）。cumoも同じAPIを持つ。CuPyの`lstsq`はdriverを選べないので、driverの関門は×。
- NumoとCumoの直接比較（`test/test_parity.rb`）は、DFloatで相対1e-12、SFloatで相対1e-4に収まった。対象は`lstsq`（x、rank、特異値）、`pinv`、`svdvals`、`svd`のs、`cond`、`norm`（froと2）、`matrix_rank`、`qr`（economic / reduceは射影QQᵀ で、`r`は絶対値で）、`null_space`（射影ZZᵀ で）。

## 計測

2つの経路を別々に測った。

- `lstsq`: `lstsq(V, y, rcond:)`を1回。numo-linalg-altは`gelsd`、cumoは`gesvd`でSVDを取ってから解を組み立てる。CuPyもSVDを使う。
- `qr`: `qr(V, mode: 'economic')`（numpy / CuPyでは`mode="reduced"`）を取り、`solve(R, Qᵀ y)`で解く。

サイズはm = 4096 / 16384 / 65536とn = 16 / 64 / 256の組み合わせ。Vは[−1, 1]上のVandermonde行列で、nが大きいと条件数が非常に大きくなる。ここでは時間だけを見る。

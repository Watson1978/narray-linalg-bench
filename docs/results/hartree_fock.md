# A. Hartree-Fock（H₂ / HeH⁺、STO-3G）

## 題材

- 積分（重なりS、1電子H_core、2電子(μν|λσ)）は、PySCF 2.14.0で1回だけ計算し、`script/hartree_fock_sto3g.json`に置いた（`script/hartree_fock_integrals.py`）。H₂ はR = 1.4 bohr、HeH⁺ はR = 1.4632 bohr。
- RHFのSCFを、P = 0（コア・ハミルトニアン）から50回回す。Fock行列はF = H + J − ½Kで、Roothaan方程式F C = S C εは`eigh(F, S)`で解く。
- 同じεを、3つの経路で求めて比べる。一般化問題を直接解く`eigh(F, S)`、`eigh(S)`から作るS^(−1/2)で標準問題にする経路、`cholesky(S)` = LからL⁻¹ F L⁻ᵀ を作る経路。

- tolは、Numoの最大値（エネルギー以外で8.2e-16）の10倍を切り上げて、1e-14にした。エネルギーはプランどおり1e-6 Ha。

- SCFのエネルギーは、2回目の反復以降、単調に下がった（上昇は最大8.9e-16で、丸め誤差の範囲）。これを関門にした（上昇 ≤ 1e-12）。最初の反復はP = 0での値（電子エネルギー0）なので除いている。
- **CuPyには一般化固有値問題の`eigh(a, b)`が無い。** Python版は`compat.eigh_general`で、CuPyでは`cholesky(S)` + `solve_triangular` 3回 + `eigh`に分解している。numpyでは`scipy.linalg.eigh(a, b, driver='gvd')`（`sygvd`）を使う。一般化の`eigvalsh`も無いので、その関門は×。
- NumoとCumoの直接比較（`test/test_parity.rb`）は、`eigh(H, S)`（固有値と、符号を除いた固有ベクトル、`turbo: true`も）と`eigvalsh(H, S)`について、DFloatで相対1e-12、SFloatで相対1e-4に収まった。

## 計測

計測用のfixtureは、HFの形を保った合成問題である（積分は使わない）。n = 128 / 512 / 1024 / 2048 / 4096の対称なHと、対角が1のSPDなS。2つの経路を別々に測った。

- `eigh_general`: 一般化固有値問題`eigh(H, S)`。Cumoは`turbo: true`で`sygvd`を1回呼ぶ。CuPyには一般化の`eigh`が無いので、`cholesky` + `solve_triangular` 3回 + `eigh`の5回の呼び出しで組む（`compat.eigh_general`）。CPUではNumoが`sygvd`（`turbo: true`）、numpyが`scipy.linalg.eigh(driver='gvd')`。
- `cholesky_solve`: `cholesky(S)`を取り、`solve(L, solve(L, H)ᵀ)`でL⁻¹ H L⁻ᵀ を作る。`solve`は一般のLU経路である（三角であることは使っていない）。

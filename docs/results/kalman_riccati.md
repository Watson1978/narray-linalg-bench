# C. Kalmanフィルタ / 離散Riccati

## 題材

- 状態8次元、観測3次元の連続時間の線形系。A_cは、対称部分が負定値になるように作った（−(GGᵀ/n + 0.5 I) + 反対称部分）。こうするとすべての固有値の実部が負になり、系は安定になる。
- `expm(A_c Δt)`（Δt = 0.1）で離散化し、2000ステップの軌道と観測をfixtureに置いた。プロセス雑音はQ、観測雑音はR = 0.1 I。
- 離散Riccatiの反復P ← A P Aᵀ − A P Cᵀ (C P Cᵀ + R)⁻¹ C P Aᵀ + Qを500回回す。経路は`solve`と`inv`の2つ。
- 定常の予測ゲインL = A P Cᵀ S⁻¹（S = C P Cᵀ + R）で、予測器x̂ₖ₊₁ = A x̂ₖ + L (yₖ − C x̂ₖ)を軌道に沿って走らせる。先頭100ステップを捨て、予測誤差の分散をPの対角と比べる。

- 物理量（trace(P) = 2.02、閉ループのスペクトル半径0.8756、cond(S) = 7.634）は、4実装で一致した。
- **Riccatiの反復は、1ステップごとに(P + Pᵀ)/2で対称化している。** 最初の版は最後に1回だけ対称化していて、4実装とも100ステップ前後で発散した。丸め誤差の非対称な成分が、反復のたびに増幅されたためである（40ステップ目で1.8e-11、80で9.5e-6、120で11）。

- NumoとCumoの直接比較（`test/test_parity.rb`）は、非正規行列の`expm`、`matrix_power`、`eigvals`の \|λ\|、`cond`、`norm(·, 2)`について、DFloatで相対1e-12、SFloatで相対1e-4に収まった。

## 計測

計測用のfixtureはn = 64 / 256 / 1024 / 4096（観測次元m = n/4）のA_c、C、Q、R。2つの経路を別々に測った。

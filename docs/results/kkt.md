# G. KKT系（等式制約付き最小二乗）

## 題材

- min ‖A x − b‖² s.t. B x = c。smallはAが32 × 16、Bが4 × 16。
- KKT行列K = [[AᵀA, Bᵀ], [B, 0]]（20 × 20、対称で不定値）を、`solve(K, [Aᵀb; c])`で解く。`driver:`は`'sym'`と`'gen'`の2つで呼ぶ。
- 別経路として、`null_space(B)`の基底Zでx = x₀ + Z yと置き、yを`lstsq(A Z, b − A x₀)`で求める。x₀ は`lstsq(B, c)`の最小ノルム解。
- `ldl(K)`でu、d、permを取り、u d uᵀ がKに戻ること、u[perm]が三角であることを見る。Kの慣性（正・負・零の固有値の数）は、`eigvalsh(K)`からもDからも(n, p, 0) = (16, 4, 0)になるはずである（Sylvesterの慣性律）。

## 関門（small、fp64、2026-10-02）

| 関門 | Numo | Cumo | numpy | CuPy |
|---|---|---|---|---|
| ‖B x − c‖ / ‖c‖ | 3.4e-16 | 5.9e-16 | 3.7e-16 | 5.9e-16 |
| Lagrange条件の残差（相対） | 3.7e-16 | 4.2e-16 | 4.1e-16 | 4.2e-16 |
| `solve`のdriver `sym`と`gen`の一致 | 0 | 0 | × | × |
| KKTと制約消去のxの差 | 1.8e-15 | 1.8e-15 | 1.3e-15 | 1.7e-15 |
| `eigvalsh(K)`からの慣性 | (16, 4, 0) | (16, 4, 0) | (16, 4, 0) | (16, 4, 0) |
| `inv(K, driver: 'sysv')`と`solve(K, I)`の差 | 1.2e-16 | 0 | 0 | 2.8e-16 |
| u d uᵀ とKの差 | 9.5e-17 | 7.2e-17 | 9.5e-17 | × |
| u[perm]の三角の外側の最大 | 0 | 0 | 0 | × |
| Dからの慣性 | (16, 4, 0) | (16, 4, 0) | (16, 4, 0) | × |

- tolは、Numoの最大値（1.8e-15）の10倍を切り上げて、2e-14にした。
- 物理量（‖x‖ = 0.9448、‖λ‖ = 1.915、‖A x − b‖ = 4.257）は、4実装で一致した。
- **CuPyには`ldl`が無い。** `ldl`の3つの関門はCuPyでは×。numpyは`scipy.linalg.ldl`で通している。scipyの既定は`lower=True`で、altの既定`uplo: 'U'`と逆なので、`lower=False`を渡してそろえた。そろえる前は、u[perm]の三角の外側が0.497になって落ちていた。
- numo-linalg-altの`solve`と`inv`は`driver:`を受け取るが使わない（常に`gesv`と`getrf` + `getri`）。そのため`sym`と`gen`の差は0になる。cumoも同じAPIを持つ。
- NumoとCumoの直接比較（`test/test_parity.rb`）は、`ldl`（uploはUとL。u、d、perm）、`eigvalsh`、`inv(driver: 'sysv')`、`solve(driver: 'sym' / 'gen')`について、DFloatで相対1e-12、SFloatで相対1e-4に収まった。permは完全一致。

## 計測

計測用のfixtureは、n + p = 512 / 1024 / 2048 / 4096（p = (n + p)/8、Aは2n × n）。経路は3つで、`ldl`はCuPyに無いのでCPUでだけ測る。

- `solve`: `solve(K, rhs)`（LU）。
- `eigvalsh`: `eigvalsh(K)`。
- `ldl`: `ldl(K)`。Numoは`sytrf`、numpyは`scipy.linalg.ldl(lower=False)`。
